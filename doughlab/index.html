도우랩

반죽을 숫자로, 레시피를 실험으로

모든 재료를 밀가루 기준 퍼센트(베이커스 %)로 다루는 제빵 레시피 앱. 수분율과 배합을 한눈에 계산하고, 구울 때마다 조건과 결과를 기록해 시행착오를 데이터로 쌓아가며 나만의 레시피를 완성하세요. 모든 기록은 기기 안에만 안전하게 저장됩니다.

주요 기능

  • 밀가루 100% 기준으로 배합 비율과 수화율을 자동 계산해요
  • 총 반죽량이나 개수만 정하면 재료 무게가 맞춰져요
  • 회차마다 사진·별점·메모를 남기고 배합을 비교해요
  • 굽기 일정을 등록하면 시작 시각에 알림이 와요
