골든타임 설정
시작 일시는 운영자 현지 시각으로 입력 → 전세계 동시 발동(절대 시각).
현재 골든타임은 나루 앱 클라이언트 연동 전이라 저장만 되고 게임 반영은 다음 릴리즈부터 적용됩니다.
활성화 시 해당 시간대에 희귀 어종 확률이 부스트됩니다.
입력한 현지 시각이 UTC로 변환되어 전세계 동시 발동됩니다.
Rare 등급 어종 출현 확률 배수 (최소 1.0)
Legendary 등급 어종 출현 확률 배수 (최소 1.0)
Mythic 등급 어종 출현 확률 배수 (최소 1.0)
활성화 시 골든타임 시작 일시에 1회성 푸시를 발송합니다.
푸시는 골든타임 활성과 별개로 동작합니다.
