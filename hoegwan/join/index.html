회관 앱에서 열면 초대 코드가 채워진 채로 매장 합류 화면이 떠요.

초대 코드
회관 앱에서 열기
  1. 앱에서 매장 이름을 확인해요
  2. 합류 요청 보내기를 눌러요
  3. 사장님이 승인하면 바로 시작해요
앱이 열리지 않나요?

앱을 설치한 뒤 이 페이지로 돌아와 다시 눌러 주세요. 또는 앱의 초대 코드 입력에 위 코드를 넣어 주세요.

회관은 지금 테스트 중이라 초대받은 분만 설치할 수 있어요. 설치 방법은 사장님께 물어봐 주세요.

초대 링크가 올바르지 않아요

링크가 잘렸거나 바뀐 것 같아요. 사장님께 초대 링크를 다시 받아 주세요. 초대 코드만 받으셨다면 회관 앱의 소속 강사예요에서 직접 넣을 수 있어요.
